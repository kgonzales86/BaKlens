# BaKlens

**An interactive Python application for bacterial genome exploration and visualization.**

BaKlens turns DNA FASTA files into interactive plots of genome composition, GC skew, and assembly statistics. Optional Bakta integration adds annotated gene and RNA features to circular and linear genome views.

The application runs locally and requires no API key.

## Features

- **FASTA validation:** accepts multi-sequence DNA FASTA files, checks IUPAC DNA characters, and rejects duplicate sequence identifiers.
- **Assembly statistics:** reports total length, sequence count, GC percentage, ambiguous-base counts, N50, and L50.
- **Contig comparisons:** visualizes contig lengths and the relationship between length, GC content, and ambiguous bases.
- **Sliding-window analysis:** plots GC content, GC skew, and ambiguous-base percentages with adjustable window sizes and step lengths.
- **Genome visualization:** displays circular composition plots and, when annotations are available, linear and circular feature tracks.
- **Bakta integration:** imports existing Bakta JSON results or launches a separately installed local Bakta pipeline.
- **Annotation exploration:** supports searches by sequence, gene, locus, and product description.
- **Export options:** downloads statistics, annotations, written summaries, and interactive HTML plots.

## Installation

Python 3.11 or 3.12 is recommended.

Clone the repository and enter the project folder:

```bash
git clone https://github.com/kgonzales86/BaKlens.git
cd BaKlens
```

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

On Windows, activate the environment with:

```powershell
.venv\Scripts\Activate.ps1
```

Install the dependencies:

```bash
python -m pip install -r requirements.txt
```

## Launch the Application

```bash
python -m streamlit run app.py --server.address 127.0.0.1 --browser.gatherUsageStats false
```

Open the local URL displayed in the terminal, usually:

```text
http://127.0.0.1:8501
```

Keep the terminal open while using the application. Press **Ctrl+C** to stop it.

For subsequent sessions, activate the environment and run the launch command again.

## Usage

### Explore a DNA FASTA

1. Select **DNA FASTA** in the sidebar.
2. Upload a `.fasta`, `.fa`, or `.fna` file.
3. Review assembly statistics and contig comparisons.
4. Select a sequence and adjust the window size and step length.
5. Explore the **GC & skew** and **Genome map** tabs.
6. Download results from **Export & methods**.

Sequence composition analysis works without Bakta.

### Import Bakta Annotations

Select **Bakta JSON** to load an existing annotation file containing both sequences and features.

Alternatively, upload a FASTA first and use **Add Bakta annotations** to attach its matching JSON results. Sequence identifiers and nucleotide sequences must match exactly.

If Bakta renamed the sequences, load its JSON directly or generate annotations using Bakta’s `--keep-contig-headers` option.

### Run Bakta Locally

Bakta and its database must be installed separately; they are not included in the Python requirements.

Follow the [official Bakta installation instructions](https://github.com/oschwengers/bakta).

Before launching BaKlens:

- Ensure the `bakta` executable is available on your terminal’s search path.
- Set `BAKTA_DB` to the installed database directory containing `version.json`.

For example:

```bash
export BAKTA_DB="/path/to/bakta/database"
```

Launch BaKlens, upload a bacterial DNA FASTA, expand **Add Bakta annotations**, and select **Run local Bakta**.

Annotation runs on the machine hosting the application. Runtime depends on the input, database, and available computing resources. The runner has a one-hour timeout.

The local Bakta runner targets Linux and macOS. Windows users can use WSL or import existing Bakta JSON results.

## Methods

| Metric | Calculation or definition |
|---|---|
| GC content | `100 × (G + C) / (A + C + G + T)` |
| GC skew | `(G − C) / (G + C)` |
| Ambiguous bases | Valid IUPAC DNA symbols other than A, C, G, and T |
| N50 | Sequence length at which sequences sorted from longest to shortest account for at least half the assembly length |
| L50 | Number of sequences required to reach that threshold |

GC percentages exclude ambiguous bases from the denominator. Assembly-wide GC content is calculated from pooled base counts rather than an unweighted average of contig percentages.

Sliding windows are calculated independently for each sequence. They never cross contig boundaries, and the final window may be shorter than the requested window size. Undefined ratios are represented as missing values.

Feature coordinates are displayed as **1-based and inclusive**.

## Interpretation and Limitations

- Bakta annotation is intended for bacterial genomes and plasmids, including bacterial metagenome-assembled genomes.
- BaKlens validates sequence formatting but does not establish organism identity.
- A circular plot is a visualization layout; it does not demonstrate that a sequence is biologically circular.
- Unusual GC content or GC skew does not independently establish contamination or identify a replication origin.
- N50 describes assembly contiguity, not assembly correctness.
- Gene annotations are predictions, not experimental confirmation.
- Written summaries are generated from calculated statistics using templates. The application does not use a generative AI model.
- The application is intended for research and education, not clinical diagnosis.

The analysis supports up to **25 million bases and 10,000 sequences**. Selected-sequence analysis is limited to 50,000 windows. Circular composition plots may be sampled for display; exported window tables retain the calculated values.

## Testing

Install pytest alongside the application dependencies:

```bash
python -m pip install pytest
python -m pytest -q
```

Tests cover sequence validation, GC calculations, ambiguous bases, N50, window boundaries, annotation matching, feature coordinates, and dashboard navigation.

The Bakta runner tests use simulated execution. A full annotation run with an installed Bakta database requires separate end-to-end validation.

## Privacy

BaKlens does not send uploaded sequences to external annotation services or AI providers. When launched locally, analysis runs on your computer.

If the application is hosted on another machine, uploaded files are processed on that host.

## Development

BaKlens was developed with assistance from ChatGPT for code generation, troubleshooting, and documentation. AI-assisted development is separate from the application’s analysis: sequence metrics are calculated by Python, and optional annotation is performed by Bakta.
